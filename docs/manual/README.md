# 用户手册

本目录是面向最终用户的使用手册，不包含任何部署或技术内容。

- 学生手册.md —— 给学生：怎么玩（做作业、养宠物、打对战、兑换奖励）
- 教师手册.md —— 给老师：怎么用（布置作业、批改、看学情、课堂做题）
- 管理员手册.md —— 给校长/信息员：怎么管（开账号、配 AI、升级、清理数据）

## 阅读方式

- 手册是 Markdown 文件，用任意 Markdown 阅读器打开即可
- 也可以推到 Git 后在网页上浏览
- 需要转成 Word / PDF 发给老师或家长时，可用任意 Markdown 转 Word 工具
