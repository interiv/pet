# 人工冒烟清单

每次改动涉及结构性调整（拆分大文件、改动经济系统结算、调整权限模型）后按本文档逐条走一遍。
每一步只需确认「现象符合预期」，不需要记录数值。

前置条件：

```bash
cd backend  && npm start          # 终端 1
cd frontend && npm run dev         # 终端 2，打开 http://localhost:5173
```

建议先用一个干净账号走完全流程，再换教师 / 管理员账号走后台部分。

---

## 一、账号与班级

| # | 操作 | 预期 |
|---|---|---|
| 1 | 注册学生账号，选择班级 | 提示「等待班主任审批」，**不能直接登录** |

| 5 | 教师在个人中心 → 任教信息 → 改任教科目 | **即时生效**，留作业时默认带出该科目 |
| 6 | 教师在个人中心 → 申请加入班级 | 状态为待审批；**该班班主任收到通知，普通任课教师不收到** |
| 7 | 用班主任账号审批通过 | 教师成为该班任课教师，可看到该班群聊 |

## 自动化兜底

人工清单之外，以下可自动跑：

```bash
cd backend  && npm test                   # API 测试
cd backend  && node tests/elements.test.js   # 属性克制规则
cd frontend && npm test                   # 前端单测（含 Admin 外壳装配冒烟）
cd frontend && npx tsc --noEmit           # 类型检查
cd frontend && npm run build              # 生产构建
```
